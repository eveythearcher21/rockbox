# SNARTY-Y1-10 navigation test build

Home opens on every native startup with exactly Music, Videos, Podcasts and Settings, in that order. Music contains Songs, Albums, Artists, Playlists, Currently Playing, Genre, Year, Search and Spotify Wrapped. The database remains the indexing engine; there is no Database folder on Home. Songs/Albums/Artists/Genre/Year/Search open their existing content directly. Back from the route's first list returns to Music. Home from the tree returns Home; Back from an album/artist opened through the playing-track context retains its previous playing-screen behavior.

Videos and Podcasts open their existing card-root folders directly. Existing files are kept, and missing folders are created by the existing bounded folder browser. Back at the folder root returns Home. Android MP4 playback retains its revision7 decoder worker and fullscreen/transient-progress layout; this release adds no new codec support.

Settings retains sound, playback, general, theme, manage-settings, time/date, Bluetooth, Android settings and recording controls where the target supports them. It also contains System, Files and Additional Features. Additional Features groups the Y1's existing Android FM Radio app, Shortcuts and Plugins. Detailed settings screens and content lists retain their normal Rockbox controls.

The four new navigation menus use SNARTY's dark background, mint selection and lavender labels. Normal labels keep the theme font's native height; the selected label grows by six pixels at 480px width, and its icon/card grow with it. The previous row shrinks. A smoothstep transition lasts about 1/6 second and runs through the ordinary input loop, without sleeping through a scroll sequence. Idle redraws also permit screen-wake refresh. Header counts and footer hints use a small readable bitmap font. The controls are the usual wheel/up/down, center to open, Back to the parent and Menu/Home to Home.

Music, Songs, Artists, Currently Playing, Genre, Year, Search, Wrapped, Videos, Podcasts, Settings, System, Files, Additional Features, Radio, Shortcuts and Plugins have purpose-specific glyphs. Albums uses the existing SNARTY database glyph and Playlists uses the existing playlist glyph, tinted with the theme colors. The Spotify-like circle/arcs are only an icon for the local listening-history feature; they do not add a Spotify connection. Existing SNARTY attribution and CC BY-SA4 sprite licensing are retained. New drawing code is GPLv2 or later.

The renderer pins the resolved loaded font ID across cache I/O, matching the normal Rockbox renderer. The legacy root selection lookup now bounds itself by the configured item count, caps that count to the actual array, and tolerates empty slots. A real simulator crash trace identified the latter issue when returning from a route absent from a shortened legacy menu. Both paths have host regression tests with ASan/UBSan.

The shared-code iPod 6G SDL simulator enables the launcher solely as a test harness; physical iPod builds are unchanged. It cannot launch the Y1 Android FM Radio app or establish Y1 timing, video decoding, standby battery life or boot reliability. All earlier runtime journal, shuffle, startup and standby behavior is retained. The dedicated partial wake lock still uses more standby battery than allowing deep sleep. Physical acceptance of this experimental layout is required before calling it stable.

Android's libmisc.so resource ZIP now includes the paired SNARTY fonts, skins and library override through tools/bundle_theme.py. The existing resource-extraction policy is retained: no new startup migration rewrites config.cfg, the music card, playlists or listening history.
