# SNARTY Y1 development download

Download `snarty-y1-download.zip` from this branch using GitHub's Download raw file button. This branch contains the delivery archive; the source patch and customization sources are inside the ZIP. Existing development branches are unchanged.

SHA-256: `3811a8e6ca81aa4d9265fbe1abea313a25f631084d031f2251730ca46ed70411`

The ZIP contains the APK, matching data/theme files, source changes, installation guide and validation report. Read README.md inside the ZIP before installing. Physical Y1 installation remains untested; speech requires a compatible installed recognition provider. Direct Android Auto/CarPlay projection is not implemented. This is an app/theme development build, not a full ROM.
